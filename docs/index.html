Python · DNS · IPv4 / IPv6 · JSON

OSINT Correlator

Lightweight CLI prototype for resolving domain names and performing reverse DNS lookups on IP addresses. It enriches a single indicator with resolver-visible DNS data; it is not an attribution or scanning platform.

Source codeDocumentation
01 / INPUT

Domain or IP

Accepts domain names, IPv4 and IPv6 indicators.

02 / RESOLUTION

DNS and PTR

Uses the system resolver for forward and reverse lookups.

03 / OUTPUT

Structured JSON

Returns the target, detected type and resolution results, including null values on lookup errors.
